研究 LIKE／LOVE／WANT／HAPPY 对实体、事件的八类表达，比较 Experiencer 与对象／Stimulus 的 flagging 框架及其共享范围，尝试构建连通语义地图。

**先读：[当前方案与进度](01_研究方案/当前方案.md)。** 当前来源要求为至少五种非印欧语言使用 De Gruyter Mouton 描写／分析材料，不限 MGL 系列。日语、芬兰语保留；韩语三轮共72条记录，按用户新范围保留54条名词形式／愿望辅助结构，Mouton 正文待核；阿姆哈拉语[第一轮27条记录](02_语言材料/阿姆哈拉语/阿姆哈拉语心理谓词_实体事件构式_例句与标注.md)，19条进入当前形式范围，Mouton章35–37页已核读，外部Y目标框架仍待补；Kayardild 为候选。老挝语、土耳其语已移出当前样本。五语的八节点材料尚未完成。

**2026-11-15 新增：[三语言英语 explications 与待测草案](03_文献笔记/NSM/三语言心理词_英语explications与待测草案_20261115.md)、[韩语母语者测试说明](02_语言材料/韩语/母语者测试/研究者说明与测试表.md)及[离线填写表](02_语言材料/韩语/母语者测试/韩语心理词_离线测试表.html)。** 整理57条材料：14条已核英语原文、5条芬兰语词族核心的项目英译、3条WANT诊断框架、35条项目草案；不是57个已经确立的词义定义。问卷含16道核心、16道扩展情境及16组成分检查，尚无受试者答案。允许多个词覆盖同一情境、各词逐项独立评分，不做互斥分类。

## 使用约定

- 当前研究范围与样本状态以[当前方案](01_研究方案/当前方案.md)为准。历史文件中的样本名单、CAUS 例句及旧来源限制不自动进入当前分析。
- 正例、缺例、未核读分别记录；没有找到不能编码成“不存在”。词典英译和书目配对不等于八节点已经覆盖。
- 笔记中的 Markdown 链接已按新位置更新；反引号内的 `research/...` 等原始资料路径统一从项目根目录定位。
- 原始资料按采集批次保留，避免破坏 PDF、抽取文本、来源记录及脚本之间的对应。通过索引查找即可，无需翻检索缓存。
- 各生成脚本是采集时的辅助工具；整理时已更新其报告输出位置，未重新生成或覆盖人工修订的例句稿。运行前请先检查其是否包含后续人工更新。

## 当前待解决问题（2026-11-14）

- **芬兰语 toivoa 的 PART／GEN 交替条件尚未研究清楚。** 实体直接宾语两种形式均有正例（PART：F48；GEN：F57–F58），不能再概括为“固定 PART”；但也未证明可以自由交替。事件名物化目前只确认 PART（F49）。仍需区分愿望／请求等义项、宾语数量与有界性、语境和体的作用，并补同词同义的对照。详见[芬兰语第二轮复核](02_语言材料/芬兰语/芬兰语心理谓词_用户复核与补例_第二轮.md)。
- 芬兰语现有58条记录，其中45条进入当前比较、13条从句暂存不处理；A不定式仍单列。问号表示缺少证据，不表示不合语法。
- 三语言 NSM 证据逐词核查，见[日语、芬兰语、韩语 NSM 释义核查](03_文献笔记/NSM/三语言心理谓词_NSM释义核查_20261114.md)。正式词项释义、WANT基元表达、名词层面的释义及一般讨论分开记录；不把同根词的定义自动移用于另一个词。
- 完整NSM释义不作为语言／词项进入比较的必要条件。已有scenario用作共同测试材料，逐词检验适用范围、必要成分和重叠；先独立界定用法，再看flagging。未经母语者验证的韩语草案及自拟情境不加入自然语料库，不自动赋最终语义节点。
