# 心理谓词跨语言比较

研究 LIKE／LOVE／WANT／HAPPY 对实体、事件的八类表达，比较 Experiencer 与对象／Stimulus 的 flagging 框架及其共享范围，尝试构建连通语义地图。

**先读：[当前方案与进度](01_研究方案/当前方案.md)。** 当前来源要求为至少五种非印欧语言使用 De Gruyter Mouton 描写／分析材料，不限 MGL 系列。日语、芬兰语保留；韩语已采第一轮，Mouton 正文待核；阿姆哈拉语待核读；Kayardild 为候选。老挝语、土耳其语已移出当前样本。五语的八节点材料尚未完成。

## 使用约定

- 当前研究范围与样本状态以[当前方案](01_研究方案/当前方案.md)为准。历史文件中的样本名单、CAUS 例句及旧来源限制不自动进入当前分析。
- 正例、缺例、未核读分别记录；没有找到不能编码成“不存在”。词典英译和书目配对不等于八节点已经覆盖。
- 笔记中的 Markdown 链接已按新位置更新；反引号内的 `research/...` 等原始资料路径统一从项目根目录定位。
- 原始资料按采集批次保留，避免破坏 PDF、抽取文本、来源记录及脚本之间的对应。通过索引查找即可，无需翻检索缓存。
- 各生成脚本是采集时的辅助工具；整理时已更新其报告输出位置，未重新生成或覆盖人工修订的例句稿。运行前请先检查其是否包含后续人工更新。
