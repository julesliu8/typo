Lit. 'like + GET/HANDLE', in the senses of 'love, like, want something'. More commonly, the concept of 'want' is simply expressed by the future/potential/desiderative verbal inflection. Basic coding frame Schema : 1-erg CC2 subj[1].obj[2].V # Microrole Coding set Argument type 1 wanter NP-erg subj.V X 2 wanted thing CC obj.V X Examples for basic coding frame : ( 132 ) Gurrany ngunthug ngangu, waga. gurrany NEG ngunthug like nga-ngu 1SG.A:3SG.P-get/handle.PST.PFV waga sit I didn't want to sit around (i.e. stay). Comment : Context: Leaving a place after a relative has passed away, not wanting to stay and be reminded.
