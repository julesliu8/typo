## 运行环境与生成器

本地 Python 环境保留于 `research/.venv/`，不进入版本管理。采集脚本仍与数据同目录；原有相互引用保持原位。

已更新四个生成器的 Markdown／矩阵输出位置，避免生成回根目录：芬兰语、土耳其语、全球扩样、早期五点位。未重新执行这些脚本，也未用旧生成器覆盖已有人工修订。

`.html`、`.txt`、`.json`、`.response` 是不同形式的采集记录；可能记录摘要、目录、访问失败或安全验证页面。文件存在不表示已获得全文或支持具体语言事实。
