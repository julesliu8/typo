`inventory.json`有57条材料：Q14、T5、P3、H35；当前词项和直接相关参照形式45行。Q为核对原图的原英语释义，T为已核芬兰语词族核心的本项目英译，P为WANT诊断框架，H为未经母语者验证的项目草案。Q/T属于作者分析，也不作为已经证明的跨语言普遍事实。`final_semantic_node`均为空。

`scenarios.json`有32道项目自拟情境，core/extension各16；`component_probes.json`有16组成分检查。受试者可以自由给多个表达，每个词分别评分，允许语义重叠；未填写的记录为未知，不能当作拒绝。情境设计、英语草案不加入原韩语自然／词典例句库，不分配新的K例号。

`goddard2018_lecture3.pdf`是用户提供的31页章节；`lecture_source.json`含原附件路径、DOI、校验值及实际核图范围；`goddard2018_lecture3.txt`为完整抽取文本。PDF页1对应印刷p.63。Goddard2018只作为方法和英语参照来源，不当作韩语词义定义来源。

生成顺序：用项目Python执行`build_materials.py`，再执行`build_form.py`。这两个脚本只更新本次材料和问卷，不改既有语料库。人工修改生成稿时应同时改源数据／脚本，否则再生会覆盖人工改动。来源记录和原始PDF独立于生成器保留。

离线表不加载外部依赖，不上传答案。默认只显示自由回答阶段；候选词部分须手动解锁。可下载JSON并重新载入接着填写；**答案不会自动保存到磁盘，关闭前需下载**。英语情境是否充分理解、实际使用的翻译与解释需要另记；未提供冒充母语审定的韩语情境译文。

`form_qa.json`记录DOM模拟环境下的12项功能检查，包括题量、候选词隐藏、多个词同时评高分、阶段切换保留答案、完整释义呈现、JSON序列化和载入。**实际浏览器访问宿主当时不可用，未完成真实浏览器视觉检查和下载按钮端到端验证。** DOM检查不冒充浏览器视觉验收。没有保存任何测试用模拟答案为受试者回答。

该问卷是一次试测材料，不是经过效度检验的标准化量表。个人母语者判断需要保留具体语境；不据此报告总体比例。
