# 韩语心理谓词：同根词的共时关系

核查日期：2026-11-14。本文区分词项、共时构词规则与历史词源，不改动既有例句的格框架编码。谚文的 Yale 式拼写转写由项目工具另行生成。

## 1. 两个判断可以同时成立

“共时还能拆出共同语素”与“已经是两个词”不是互斥项。一个词可以有透明的内部构造，同时具有独立的词义、词类、配价和词典词条。需要分别问：

1. 是否存在现代语言中的共同词基及构式？
2. 这一构式是否能推广到其他适合的词基？
3. 具体产物的意义和配价是否完全可预测，还是已有词汇化？
4. 所谓共同部分是否其实只有词源上的联系？

下文的“形容词／动词”沿用韩国国立国语院的词类分类；这些形容词本身可以作谓语，不能据此套用汉语的句法分布。词典形末尾的 -다（-ta） 是引述词典形式所用的结尾，不是本表所讨论的心理谓词派生手段。

## 2. 当前词表中的主要关系

|词项|共时分析与关系|研究中应如何处理|
|---|---|---|
|좋다（cohta） → 좋아하다（cohahata）|可分析为 좋-（coh-） + -아（-a） + 하-（ha-）；共享 좋-（coh-）。后者是动词，有常用 LIKE 义，也有表露高兴等其他义项。|保留两个词项，记录透明构词联系；不能把所有义项归为同一个“形容词的动词形式”。|
|기쁘다（kipputa） → 기뻐하다（kippehata）|可分析为 기쁘-（kippu-） + -어（-e） + 하-（ha-）；元音交替使 기쁘-어（kippu-e） 实现为 기뻐-（kippe-）。是同一种 A-아（A-a）/어 하다（e hata） 构式。|保留两个词项并连接派生关系；后者不仅有 ACC，也有 -에（-ey），不编码为机械的 NOM→ACC 规则。|
|즐겁다（culkepta） → 즐거워하다（culkewehata）|可分析为 즐겁-（culkep-） + -어（-e） + 하-（ha-）；ㅂ（p） 不规则交替产生 즐거워-（culkewe-）。官方基础词典明确把后者列为前者的派生词。|这是可与前两组比较的现代构词关系。后者尚未补入原有正式例句表，不凭构词规则补写其格框架。|
|즐겁다（culkepta） ↔ 즐기다（culkita）|官方词源条目给出相同的历史词基，分别接不同历史派生成分。现有证据尚不足以确认一条现代能产的相互派生规则。|暂按有历史联系的两个词项处理；不把 즐기다（culkita） 切成“즐-（cul-） + 名物化 -기（-ki）”，也不把它等同于 즐거워하다（culkewehata）。|
|사랑하다（salanghata）、행복하다（hayngpokhata）、만족하다（mancokhata）|可以识别 사랑（salang）／행복（hayngpok）／만족（mancok） 与 -하-（-ha-）；这是名词词基加 -하다（-hata） 的另一类构词。|共同的是构词成分 하-（ha-），不是共同的情感词根。各词类、义项与格框架分别核查。|

## 3. A-아（A-a）/어 하다（e hata）：有现代规则，但不保证所有产物同义同配价

[《标准国语大辞典》하다（hata），Ⅱ 辅助动词第8义](https://stdict.korean.go.kr/search/searchView.do?word_no=363685)明确列出形容词后的 -어하다（-ehata） 构式，释义为对前项所指对象具有相应感受。它还指出，这个构式可以加在包含 싶다（siphta） 的短语等较大单位后；因此不能把它完全看成几个孤立词的偶然词尾相似。

分析术语有不同层次：该词典把这里的 하다（hata） 列为辅助动词；[Yoon 2003，p.112，§3.5.1](https://doi.org/10.25911/5d5158f90d84d)在分析 좋아하다（cohahata） 时把 -aha- 称为 verbaliser。论文中可以采用较中性的“形容词词基 + -아（-a）/어 하다（e hata） 构式”，并交代来源的术语，不必先裁定它只能是后缀派生或只能是句法组合。

这一构式大致把形容词表达的评价／感受状态，组织成对某对象持有相应感受的动词性表达。然而，具体词项仍会词汇化：

- [좋아하다（cohahata）](https://stdict.korean.go.kr/search/searchView.do?word_no=477134)有对象喜好、饮食偏好、活动偏好、人际喜欢，以及表露高兴等不同义项。Yoon 对 attraction 的论述服务于 GOOD／LIKE 的区分，不能代替整部词典的全部多义分析。
- [기뻐하다（kippehata）](https://stdict.korean.go.kr/search/searchView.do?word_no=405463)既有“感到喜悦”的用法，也列出针对某事／事实的 -에（-ey） 和 ACC 框架。因此，透明构词不等于每次都新增一个 ACC 论元。
- 对视角、信息来源和人称的限制，需要另做语境核查。这里不将这些词简化为第一人称形与第三人称形，也不把后者一律定义为主动、可控地“表现情绪”。

**这不是使役规则。** 不能把“感到高兴”的动词直接读作“使另一个人高兴”。同一词典把 -게 하다（-key hata） 使役构式另列在辅助动词第1义，跟这里的第8义不同。它们可以继续留在本项目的非使役样本中。

用户排除的是 Y 以非名物化分句实现的框架。词内部／谓词组合中的 -아（-a）/어（e） 不自动构成一个要剔除的“事件 Y 分句”；仍需看 Y 的外层实现。对已经有词典词条的 좋아하다（cohahata） 等，不因为内部分析有连接成分便删除其 NP 证据。

## 4. 즐겁다（culkepta）／즐기다（culkita）：历史关系确实，但共时切分暂不定论

[즐겁다（culkepta） 的词源条目](https://stdict.korean.go.kr/search/searchView.do?word_no=483118)与[즐기다（culkita） 的词源条目](https://stdict.korean.go.kr/search/searchView.do?word_no=483119)指向同一个历史词基。尤其后者的历史派生成分标为 -이-（-i-），并不是现代名物化词尾 -기（-ki）。

这能证明同源，不能单独证明现代说话人仍掌握一个可推广的“즐겁다（culkepta） → 즐기다（culkita）”构词规则。本文既不宣布它们绝对不可共时分析，也不凭相似字形创造现代词根与后缀；暂记“历史同根；共时派生关系未确认”。

相比之下，[官方基础词典 즐겁다（culkepta） 条目](https://krdict.korean.go.kr/eng/dicSearch/SearchView?nation=eng&nationCode=6&ParaWordNo=62101)直接列出 즐거워하다（culkewehata） 为派生词，为现代 A-아（A-a）/어 하다（e hata） 分析提供了独立依据。

## 5. 名词／词根 + -하다（-hata） 是另一类构词

[官方后缀 -하다（-hata） 条目](https://stdict.korean.go.kr/search/searchView.do?word_no=498072)把名词后形成动词、形成形容词等用法分别列出。条目直接以 사랑하다（salanghata） 为名词→动词例，以 행복하다（hayngpokhata） 为名词→形容词例。因此可以分析爱情／幸福等名词词基与 하-（ha-），但不能把 하-（ha-） 一概赋义为“情绪的行为化”。

还需逐义项看词类：[만족하다（mancokhata）](https://stdict.korean.go.kr/search/searchView.do?word_no=423287)的同一词条下同时列出动词和形容词部分。单凭末尾有 -하다（-hata），不能推断其一定带 ACC，或一定与另一个形容词构成同一种交替。원하다（wenhata） 的 WANT 义是汉字“願”所对应的条目，也不能仅凭形式相似混入“怨”的同音条目。

## 6. 对语义地图与统计的建议

数据分开保留三个层次：**词项＋义项、构词关系、实际格框架**。

- 每个词项的名词／事件 NP 框架继续由实际例句支持，不因同根而自动补齐或合并。
- 为 좋다（cohta）／좋아하다（cohahata）、기쁘다（kipputa）／기뻐하다（kippehata） 等增加“透明 A-아（A-a）/어 하다（e hata） 家族”的关系标签；为 즐겁다（culkepta）／즐기다（culkita） 暂记历史联系。
- 如果地图按表面构式合并意义覆盖，可研究同一形态构式对多个词基的适用情况；但要区分真正能产的模式和词汇化产物，不能单凭都有 하-（ha-） 就合为一个构式。
- 如果统计若干词项共同表现出 NOM／ACC 差别，应说明其中多少来自同一种构词机制。不能把同一机制的几个产物直接当作彼此独立的多条支持证据。

现阶段最值得继续验证的假设是：**韩语中，一部分感受／评价形容词与 A-아（A-a）/어 하다（e hata） 形式之间，存在系统的谓词类型和论元编码差异。** 这只是语言内部的候选规律，尚不是无例外的 NOM→ACC 规则，也不能直接当作跨语言蕴含共性。
